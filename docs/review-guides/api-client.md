# Review guide: API clients

- Consumers call the REST API only through the client generated by `@taico/openapi-sdkgen` from the backend's OpenAPI spec.
- No `fetch`, `axios` or hand-written request wiring exists in feature code.
- Generated files are not edited by hand and are produced by the build, not committed edits.
- New or changed REST routes appear in the OpenAPI spec with request and response schemas and a tag.
- Decimal amounts are typed as strings in the spec and client.
- Spec changes avoid schema features the generator does not support (`allOf`/`oneOf`/`anyOf`, file uploads, cookie parameters), or the generator is extended upstream.
- Client instances are created per session/user with `getAccessToken` (or a cookie session); there is no global client holding one user's token.
